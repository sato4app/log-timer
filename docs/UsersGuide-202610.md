# log-timer 利用者の手引

**バージョン:** v18
**最終更新日:** 2026年10月1日

---

## 1. このアプリについて

「log-timer」は、タバタ式などのインターバルトレーニングに使う運動タイマーです。
「**準備 → 運動 → 休憩**」を、決めた回数だけ自動でくり返します。
切り替わりや終わり際は、**音声の読み上げ**か**電子音**で知らせるので、画面を見ていなくても運動に集中できます。

最後まで終えた運動は自動で記録され、あとから一覧やカレンダーで振り返れます。

### 動作環境
- スマートフォン／パソコンの最新の Web ブラウザ（Chrome、Safari など）
- 一度開けば、2回目からはインターネットにつながっていなくても使えます

### アプリのインストール（ホーム画面に追加）
ホーム画面に追加すると、ふつうのアプリと同じように全画面で起動できます。

- **Android（Chrome）:** 画面右上に「**ホーム画面に追加**」が出ていれば、それを押します。
  出ていないときは、ブラウザのメニューから「アプリをインストール」を選びます
- **iPhone・iPad（Safari）:** 共有ボタンから「**ホーム画面に追加**」を選びます

### はじめて開いたとき
画面の使い方を案内する「**使い方ガイド**」が自動で出ます（→第9章）。
ひと通り見ておくと、すぐに使い始められます。

## 2. 画面の構成

画面は上から次の順に並んでいます。

| 場所 | 内容 |
| --- | --- |
| いちばん上 | 左: アプリ名「log-timer」（押すと更新の確認）／右: 「使い方」、音の切り替え、「QR」 |
| タイマー | 左: 残り時間（または経過時間）を表す円／右: 「スタート」、「リセット」、表示方法の切り替え（↓ ↑） |
| 設定 | 準備・運動・休憩の秒数と回数、合計時間、既定値のボタン |
| 履歴 | これまでの運動の記録、または日ごとの回数のカレンダー |

### 色の意味
画面の背景色は、いまのフェーズによって変わります。

| 色 | フェーズ |
| --- | --- |
| 紺 | 開始待ち |
| 青 | 準備 |
| 赤 | 運動 |
| 緑 | 休憩 |
| 紫 | 完了 |

円の中には、フェーズ名、秒数、「何回目か」（例: 2 / 3 回目）が出ます。
60秒以上は「1:30」のように分と秒で表します。

## 3. 時間と回数を決める

設定欄で、4つの値を決めます。

| 項目 | はじめの値 | 決められる範囲 |
| --- | --- | --- |
| 準備 | 10 秒 | 0〜599 秒 |
| 運動 | 20 秒 | 1〜599 秒 |
| 休憩 | 5 秒 | 0〜599 秒 |
| 回数 | 3 回 | 1〜99 回 |

### 値の変え方
- **数字を直接入れる:** 数字の欄をタップすると空欄になるので、新しい値を入れます。
  何も入れずに欄の外をタップすると、元の値に戻ります。範囲を超えた値は、上限（下限）に直します
- **＋ − で増減する:** 1 ずつ増やしたり減らしたりします

設定欄の右上には、全体にかかる時間（例: 合計 1分25秒）が出ます。
最後の運動のあとには休憩が入らないので、その分は合計に含みません。

> **準備や休憩を 0 秒にすると、そのフェーズは飛ばします。** たとえば準備を 0 秒にすると、すぐに運動から始まります。

> タイマーが動いている間は、設定を変えられません。
> **一時停止中は変えられます。** 変えた値は**次のフェーズから**使い、止めていたフェーズは元の長さのまま最後まで進みます
> （たとえば運動の途中で止めて運動の秒数を変えると、いまの運動は元の秒数のまま終わり、次の運動から新しい秒数になります）。
> 回数は、いま何回目かより少なくはできません。

### よく使う設定を覚えさせる（既定値）
- **既定値に設定:** いまの設定を「既定値」として覚えます。次にアプリを開いたときも、この値で立ち上がります
- **既定値に戻す:** 覚えさせた既定値に戻します。ボタンには既定値の中身が出ます（例: 既定値に戻す（10/20/5/3回））

いまの設定が既定値と同じときは、どちらのボタンも押せません（押す必要がないため）。

## 4. 運動を始める・止める

| ボタン | 動き |
| --- | --- |
| **スタート** | タイマーを最初から始めます |
| **一時停止** | 動いている間は「スタート」がこの表示に変わります。押すとその場で止まります |
| **再開** | 一時停止中の表示です。押すと続きから動きます |
| **リセット** | 最初の状態（開始待ち）に戻します |

最後の運動が終わると「**完了**」になり、背景が紫に変わって「全 3 回 終了」のように出ます。
もう一度「スタート」を押すと、同じ設定で最初から始まります。

> タイマーが動いている間は、画面が自動で暗くなったり消えたりしないようにしています（対応しているブラウザのみ）。

---

## 5. カウントダウンとカウントアップ

タイマーの右側にある 2 つの矢印のボタンで、数字の進み方を選びます。選んでいる方が白くなります。

| ボタン | 表示 | 運動 20 秒のとき |
| --- | --- | --- |
| **↓** | カウントダウン（残り時間） | 20、19 … 1 と減る。円も少しずつ減る |
| **↑** | カウントアップ（経過時間） | 0、1 … 19 と増える。円も少しずつ増える |

タイマーが動いている途中でも切り替えられます。

> アプリを開き直すと、表示はカウントダウン（↓）に戻ります。

## 6. 音の鳴らし方

画面右上の音のボタンを押すたびに、「**音声 → 電子音 → 音 オフ**」の順に切り替わります。
ボタンには、いま選んでいる方式が出ます。選んだ方式は、次にアプリを開いたときも引き継ぎます。

### 音声
フェーズが切り替わるたびに、名前を読み上げます。

- 「準備」「運動 1 回目」「休憩」「運動 2 回目」…、最後は「終了。お疲れさまでした」
- **運動の間は、毎秒数字を読み上げます。** 数字は画面の表示に合わせます（運動 20 秒のとき）
  - カウントダウン（↓）: 「20」「19」…「1」、終わる瞬間に「0」
  - カウントアップ（↑）: 「1」「2」…「19」、終わる瞬間に「20」
- **準備と休憩は数字を読まず、電子音で知らせます**（次の「電子音」と同じ鳴り方）

> 「運動 ○ 回目」を言い終えるまでは数字を読まないので、運動の始めの 1〜2 秒の数字は飛びます。
> フェーズ名が途中で切れないようにするためです。

> 最後の数字（「0」や「20」）は運動が終わる瞬間に読むので、次の「休憩」などはそれを言い終えてから始まります。

### 電子音
数字は読まず、ビープ音で知らせます。

- 各フェーズの**残り 3 秒**から「ピッ・ピッ・ピッ」と鳴り、終わる瞬間だけ高く長めに「**ポーン**」と鳴ります（時報と同じ区切り方です）
- 運動と、準備・休憩とでは、始まりの音の高さが違います
- 最後まで終えると、「終わり」の 2 音が続けて鳴ります

カウントダウン・カウントアップのどちらの表示でも、同じように鳴ります。

### 音 オフ
音を鳴らしません。

> 読み上げに対応していないブラウザでは、「音声」は選べません（「電子音 → 音 オフ」の 2 つだけになります）。

> 音声と電子音は、使い方ガイドの中で実際に聞き比べられます（→9.3）。

## 7. 運動の記録（履歴）

**最後まで終えた運動**は、画面下の「履歴」に自動で記録されます。
途中でリセットした運動と、使い方ガイドの試し実行は記録しません。

### 一覧の見方
1 行が 1 回分で、新しいものが上に来ます。

| 列 | 内容 |
| --- | --- |
| 日時 | 運動を終えた日時（例: 2026/10/01 07:30） |
| 準備・運動・休憩 | そのときの秒数 |
| 回数 | そのときの回数 |
| 矢印 | そのときの表示方法（↓ カウントダウン／↑ カウントアップ） |

記録は端末の中に**最大 50 件**まで残り、それを超えると古いものから消えます。

### 過去の設定を呼び出す
履歴の行をタップすると、その行の**設定（準備・運動・休憩・回数）と表示方法（↓ / ↑）を読み込みます**。
読み込んだだけでは始まりません。**「スタート」を押して始めてください。**

- 一時停止中や完了後に読み込んだときも、読み込んだ設定で最初からになります
- 古い記録で矢印が出ていない行は、表示方法をいまのままにします
- タイマーが動いている間は、履歴をタップできません

### 記録をすべて消す
履歴の右上の「**全消去**」を押すと、「履歴をすべて消去します。元に戻せませんが、よろしいですか？」と確認が出ます。
「OK」を押すと記録をすべて消します。**消した記録は元に戻せません。** やめるときは「キャンセル」を押します。
タイマーが動いている間は押せません。

---

## 8. 日ごとの回数を見る（カレンダー）

履歴の右上にある 2 つのアイコンで、表示を切り替えます。

| アイコン | 表示 |
| --- | --- |
| リスト（横線） | 記録の一覧 |
| カレンダー | 日ごとの実施回数（月のカレンダー） |

カレンダーでは、運動した日に ☆ が付きます。

| その日の回数 | 印 |
| --- | --- |
| 1 回 | ☆ |
| 2 回 | ☆☆ |
| 3 回 | ☆☆☆ |
| 4 回以上 | ☆4、☆5 … |

- 上の見出しに、その月の合計回数（例: 計 12 回）が出ます
- **‹ ›** で前の月・次の月に移ります
- 今日の日付は枠で囲んで表示します
- カレンダーを出している間は、設定欄を隠してカレンダーを広く表示します。設定を変えるときは、リストのアイコンで一覧に戻してください

> 数えるのは、端末に残っている記録（最大 50 件）の分だけです。

## 9. 使い方ガイド

画面右上の「**使い方**」を押すと、画面の場所をひとつずつ光らせながら操作を案内します。
はじめてアプリを開いたときは自動で出ます。タイマーが動いている間は開けません。

### 9.1 操作のしかた
- **光っている場所は、そのまま押して試せます。** 説明を読みながら実際に操作できます
- 吹き出しの「**次へ**」「**戻る**」でページを移り、「**閉じる**」で終わります（最後のページは「終わり」）
- パソコンでは、→ で次へ、← で戻る、Esc で閉じます

### 9.2 ご案内する内容（全 7 ページ）
1. log-timer の使い方
2. 時間と回数を決める
3. 始める・止める
4. カウントダウンとカウントアップ
5. 音の鳴らし方
6. 記録を振り返る
7. 更新の確認と QRコード

### 9.3 音を聞いてみる
「音の鳴らし方」のページには「**音を聞いてみる（12秒）**」ボタンがあります。
押すと、準備 2 秒・運動 4 秒・休憩 2 秒・2 回の短い設定で、実際にタイマーが動きます。
上の音のボタンで「音声」「電子音」を切り替えながら、聞き比べてみてください。

- 途中で止めるときは「試し実行を止める」を押します
- この試し実行は履歴に残りません。終わると、設定は元に戻ります

## 10. QRコードで知らせる

画面右上の「**QR**」を押すと、このアプリのページの QRコードが出ます。
家族や友人のスマホのカメラで読み取ってもらえば、同じアプリをすぐに開けます。

QRコードの下には、ページのアドレスも文字で出ます。
画面のどこかをタップするか「閉じる」を押すと閉じます。

---

## 11. アプリを最新にする

画面左上のアプリ名「**log-timer**」をタップすると、新しい版が出ていないかを確かめます
（見た目はふつうの文字ですが、押せるようになっています）。

| 表示 | 意味 |
| --- | --- |
| 確認中… | 確かめているところです |
| 最新です（v18） | いまの版が最新です |
| 更新中… | 新しい版が見つかったので取り込んでいます。このあと自動で読み込み直します |
| 確認できません | インターネットにつながっていないなどで、確かめられませんでした |
| 実行中は確認しません | タイマーが動いている間は確かめません（読み込み直すと、運動の途中経過が消えるため） |

結果は数秒で消えます。

## 12. パソコンのキーボード操作

| キー | 動き |
| --- | --- |
| スペース | スタート／一時停止／再開 |
| R | リセット |

数字の欄に入力している間は、キー操作は効きません。
使い方ガイドを出している間は → ← Esc だけ（→9.1）、QRコードを出している間は Esc（閉じる）だけが効きます。

## 13. 困ったとき

| こんなとき | 原因と対処 |
| --- | --- |
| 「音声」が選べない | お使いのブラウザが読み上げに対応していません。「電子音」をお使いください |
| 運動の始めの数字が読まれない | 「運動 ○ 回目」を言い終えてから数字を読むためで、故障ではありません（→第6章） |
| 設定が変えられない | タイマーが動いている間は変えられません。一時停止するかリセットしてください |
| 一時停止中に秒数を変えたのに、いまのフェーズが変わらない | 変えた値は次のフェーズから使います（→第3章） |
| 回数を減らせない | 一時停止中は、いま何回目かより少なくはできません |
| 履歴をタップしても始まらない | 履歴は設定を読み込むだけです。「スタート」を押してください（→第7章） |
| 開き直したら ↑ が ↓ に戻った | 表示方法は覚えておきません。毎回、開いたときはカウントダウンになります |
| 「使い方」が押せない | タイマーが動いている間は開けません |
| 記録や既定値が消えた | 記録と既定値はブラウザの中に保存しています。ブラウザのデータ（サイトのデータ）を消すと、一緒に消えます |
