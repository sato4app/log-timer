## logTimer - 運動の記録用アプリ

タバタ式インターバルに対応した運動タイマーです。
「準備 → 運動 → 休憩」を指定した回数だけ繰り返します。
PWA なのでスマホのホーム画面に追加でき、オフラインでも動きます。

### 機能

- **時間・回数の設定**（実行中は変更不可）
  | 項目 | 既定値 | 範囲 |
  | --- | --- | --- |
  | 準備 | 10 秒 | 0〜599 秒 |
  | 運動 | 20 秒 | 1〜599 秒 |
  | 休憩 | 5 秒 | 0〜599 秒 |
  | 回数 | 3 回 | 1〜99 回 |
- **表示方法の切り替え**: カウントダウン（残り時間）／カウントアップ（経過時間）
- 進捗リングとフェーズ別の背景色（準備=青 / 運動=赤 / 休憩=緑 / 完了=紫）
- 音によるフェーズ切り替え通知と残り3秒からの秒読み（オン・オフ可）
- 一時停止・再開・リセット
- 実行中は画面のスリープを抑止（対応ブラウザのみ）
- キーボード操作: スペースキー = 開始 / 一時停止、R キー = リセット

準備や休憩を 0 秒にすると、そのフェーズは読み飛ばされます。

### スマホで使う

**Service Worker は HTTPS か localhost でしか動きません。**
PC のローカルサーバーに LAN 経由（`http://192.168.x.x:8000` など）でアクセスすると
タイマーは動きますが、ホーム画面への追加とオフライン実行はできません。
スマホで PWA として使うには HTTPS で配信してください。

GitHub Pages を使う場合（このリポジトリは `sato4app/logTimer`）:

1. GitHub にプッシュする
2. リポジトリの Settings → Pages で Source を `main` ブランチのルートに設定する
3. スマホのブラウザで `https://sato4app.github.io/logTimer/` を開く

ホーム画面への追加:

- **Android (Chrome)**: 画面右上の「ホーム画面に追加」ボタン、またはメニューの「アプリをインストール」
- **iPhone (Safari)**: 共有ボタン → 「ホーム画面に追加」
  （iOS は追加ボタンを自動表示できないため手動操作が必要です）

追加後は全画面（standalone）で起動し、機内モードでも動作します。

### PC で動かす（開発時）

`app.js` を Babel が読み込むため、`file://` で直接開くと動作しません。
ローカルサーバーを起動してください。

```bash
python -m http.server 8000
# または
npx serve .
```

ブラウザで http://localhost:8000 を開きます。

### ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | CDN 読み込み、PWA 用メタタグ、マウント先 |
| `app.js` | React コンポーネント（JSX、Babel でブラウザ内変換） |
| `manifest.json` | アプリ名・アイコン・表示方法の定義 |
| `service-worker.js` | オフライン用キャッシュ |
| `icon-180.png` | iOS ホーム画面用（apple-touch-icon） |
| `icon-192.png` / `icon-512.png` | マニフェスト用（any / maskable 兼用） |

### 技術

- React 18（CDN / UMD）
- Tailwind CSS（CDN）
- Babel standalone（ブラウザ内で JSX を変換）
- Web Audio API（ビープ音）、Screen Wake Lock API（スリープ抑止）

計時は `setInterval` のカウントではなく終了時刻（実時刻）との差分で行うため、
タブが裏に回っても時間がずれません。

CDN から読み込むライブラリも Service Worker がキャッシュするため、
2 回目以降の起動はオフラインでも完結します。
ファイルを更新したときは `service-worker.js` の `CACHE_NAME` の版数を上げてください。
古いキャッシュが破棄されて新しいファイルに入れ替わります。
